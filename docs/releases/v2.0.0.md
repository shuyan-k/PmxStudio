## PmxStudio v2.0.0

这一版把 PmxStudio 从单模型查看器扩展成**多模型场景**：一次导入多个 PMX，在同一画面里各自摆放、显示与演算；同时内置可选的**材质扩展**（法线 / 金属度 / 粗糙度）插件，并重做了启动流程、检查器与菜单布局。相机方向、地面阴影与贴图透明分类的几处长期问题也在此版修正。

### 新增

**多模型场景**

- 一次拖入多个 `.pmx`，或从「文件 → 场景模型…」/「场景模型」工具窗口导入，即可在主模型之外继续追加模型。
- 每个额外模型拥有独立的姿态、物理世界与渲染资源，可单独设置位置、朝向、缩放与显示开关；跟随全局物理开关演算各自的头发 / 衣服。
- 修改摆放会重建该模型的蒙皮与物理数据；移除后自动重新绑定剩余模型的姿态与物理引用。视口与渲染输出都会绘制场景模型，阴影按模型分别投射。
- Agent API 新增 `scene.models` / `scene.model_add` / `scene.model_set` / `scene.model_remove`，`scene.state` 增加 `scene_models` 计数。

**材质扩展插件（法线 / 金属度）**

- 内置可选插件，默认关闭；「设置 → 插件」开启后按漫反射贴图文件名自动配对：
  - `<贴图名>_normal.png`（或 `_n`）：切线空间法线贴图，TBN 由屏幕空间导数生成，PMX 无需预计算切线。
  - `<贴图名>_orm.png`：G = 粗糙度，B = 金属度（glTF ORM 约定）。
  - `<贴图名>_metallic.png`：灰度金属度，没有 ORM 时使用。
- 支持 png / jpg / jpeg / bmp / tga / dds；法线强度 0–2 可调；找不到对应文件时材质保持原样，关闭插件时渲染与原版完全一致。
- 「缺少法线贴图时自动生成」把漫反射亮度当高度场（3×3 平滑 + Sobel）生成法线，按材质缓存一次。
- Agent API：`scene.settings` 支持 `material_ext` / `normal_auto` / `normal_strength`。

**启动加载窗**

- 启动时先显示居中的独立小窗，展示名称、版本、当前阶段与进度；着色器编译、模型载入、物理构建与插件扫描完成后才打开主窗口。
- 加载窗至少停留 0.4 秒，小模型不会一闪而过。

### 改进

**界面**

- 启动默认进入预览模式（此前默认编辑模式）。
- 检查器精简：编辑模式保留信息 / 骨骼 / 表示枠 / 顶点 / 材质 / 面 / 形态 / 物理 / 柔体 / 附件 十个数据标签，预览模式只保留动作 / 时间线 / 形态 / 物理 / 附件 五个高频标签。
- 场景模型、相机、灯光、烘焙、渲染输出、肉体与设置改为菜单打开的工具窗口，可拖动、可同时展开；`Ctrl+,` 打开设置。
- 移除重复的「编辑」菜单：撤销 / 重做并入「文件」，「检索」并入「视图」；修复模式切换按钮与菜单的 ImGui ID 冲突。
- 骨骼分类支持连续勾选；选中骨骼不再自动弹出检索窗口。
- 贴图透明度按材质实际使用的 UV 区域判断，减少图集边缘透明像素造成的误判。

### 修复

- 相机改用左手系视图，修复正视图下模型与 MMD 左右镜像。
- 修正正交投影矩阵行主序错误，恢复真实模型的地面阴影。
- 法线贴图改用独立纹理单元，修复覆盖阴影贴图导致的假阴影。
- 修复脸部白斑与异常张嘴：不再把贴图边缘的抗锯齿透明像素当成整张贴图透明。
- 静止预览时只在姿态变化后解 IK，消除腿部微抖；渲染快照不再重复重解 IK。
- 修复非 ASCII 贴图名在 Windows 上导致的 `0xC0000409` 崩溃。
- 钳制蒙皮索引，并限制自动法线贴图的显存占用。
- 修复反复导入模型后自动法线贴图泄漏导致的闪退。
- 修复场景模型移除时的引用错位与退出时 GL 资源释放顺序。
- 新增相机视图约定与多模型摆放变换的测试，`pmx_tests` 增至 307 项检查。

### 实验性 / 暂未启用

- GPU 肉体接触求解保持禁用（`kFleshEnabled = false`），与 v1.1.2 相同，后续单独打磨。

### 已知问题

- 场景里的额外模型各自独立：不与主模型互相碰撞，没有独立 VMD 轨道，不能直接拾取 / 编辑骨骼；阴影按模型分别投射，模型之间不会互相投影 / 承接，重叠处的接影会叠加变深；额外模型不写入主模型的保存文件。
- 材质扩展依赖文件名约定；自动生成的法线来自漫反射明暗，脸部彩绘这类画好的明暗可能产生不自然凹凸，可随时关闭。
- 非 Windows 平台仍缺少 CP932 → UTF-8 转换表，日文名称按原始字节保留。
