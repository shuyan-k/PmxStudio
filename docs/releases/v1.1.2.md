## PmxStudio v1.1.2

这一版补上了两类长期缺失的能力：**附件模型**与**骨骼分类**。现在可以把帽子、假面、挂饰等单独 PMX 叠到主模型上，附件自带的骨骼与物理会跟着动作一起摆动；骨骼叠加层也能按体干、四肢、头发、衣服等类别分组显示或隐藏。

### 新增

**附件模型**

- 「附件」面板可导入任意 PMX，作为运行时叠加层与主模型一起渲染，不修改、不写入主模型数据。
- 附件可绑定到主模型的任意骨骼（默认「頭」），并支持位置 / 旋转 / 缩放摆放；拖动摆放时只回传附件段顶点，不重建整个模型。
- 附件自带的骨骼层级、蒙皮与物理会独立求值：垂饰、流苏一类用关节连接的部件会跟随头部运动与重力摆动。
- 附件物理的总开关、重力与迭代次数跟随主模型物理面板；提供「重置附件物理」按钮。
- 预览模式与导出渲染都会推进附件物理，视口与成片表现一致。
- 移除附件后立即恢复主模型原始顶点。

**骨骼分类**

- 按日文 / 中文 / 英文骨骼名自动识别：体干、四肢、头发、衣服、饰品、道具、其他。
- 顶部「视图 → 骨骼」子菜单可直接开关各分类；「骨骼」面板显示每类数量，并提供「全部显示 / 全部隐藏」。
- 单根骨骼可手动指定分类，或点「自动识别」恢复；骨骼改名 / 增删后自动重新分类。
- 分类隐藏后，骨骼叠加层与视口拾取同时生效，不会点到看不见的骨骼。

**Agent API**

- 新增 `model.accessory_load` / `model.accessory_set` / `model.accessory` / `model.accessory_clear`。
- 新增 `bone.categories`，可按类别查询数量与显隐、设置开关。
- `bone.list` 增加 `category` / `category_name` / `visible` 字段；`model.accessory` 返回附件骨骼世界位置与局部旋转。

### 改进

- 骨骼 / 刚体 / 关节叠加层改用独立的固定光照方向，调整模型灯光不再影响辅助层明暗。
- 版本号统一：CMake、Agent API `system.info` 与「帮助」菜单均显示 1.1.2（此前仍残留 0.1.0）。
- README 补充附件、骨骼分类、新 API 命令、面板数量与已知限制；测试数量更新为 280 项。

### 实验性 / 暂未启用

- GPU 肉体接触求解（Compute Shader、Corner Taper、外部碰撞体、烘焙缓存与多线程）已完成实现与静止误判修复，但当前观感仍未达到可发布标准，**本版保持禁用**（`kFleshEnabled = false`），后续单独打磨。

### 已知问题

- 附件物理与主模型物理是两个独立世界：附件只与自身刚体 / 关节碰撞，不与主模型的头发、衣服碰撞；附件也没有独立 VMD 轨道，只跟随锚点骨骼与自身物理。
- 骨骼分类基于名称关键词，私有命名可能落入「其他」；手动分类只在当前运行期有效，骨骼增删后会重新识别。
- 非 Windows 平台仍缺少 CP932 → UTF-8 转换表，日文名称按原始字节保留。
